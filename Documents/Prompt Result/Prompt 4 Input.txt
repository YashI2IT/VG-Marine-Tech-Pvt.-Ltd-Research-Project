# 12. BENCHMARKING MUST BE FAIR

When we eventually benchmark the virtual sensor:

* Use the same data conditions wherever possible.
* Clearly separate training, validation and test data.
* Avoid leakage.
* Report the exact split.
* Record preprocessing configuration.
* Record random seed.
* Record model version.
* Record code commit.
* Report metrics with their test conditions.
* Compare against transparent baselines.
* Do not cherry-pick favorable samples.
* Do not compare incompatible datasets without clearly labeling the comparison.

The benchmark should be reproducible and traceable.
