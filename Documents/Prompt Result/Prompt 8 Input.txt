# FINAL DECISION RULE

Do not make architectural decisions merely because a document mentions a technology.

The analysis should distinguish:

```text
Company Requirement
        vs
Company Recommended Technology
        vs
Research Recommendation
        vs
Implementation Detail
        vs
Open Decision
```

For example:

```text
"Need real-time telemetry"
        ≠
"Must use technology X"
```

unless the company documentation explicitly requires that technology.

Similarly:

```text
"Need virtual temperature estimation"
        ≠
"Final model must be CNN-LSTM"
```

unless that is formally established as a project requirement.

The purpose is to understand the **engineering objective first**, then determine implementation decisions later.
